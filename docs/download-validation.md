## 本轮发现并修复

迁移目标已有同名不同内容文件时，助手会保存为带校验和后缀的文件。如果在移动成功后、迁移记录写入前中断，旧恢复逻辑只检查原目标名，误报找不到源文件。恢复现在检查原目标名和确定性的版本文件名，并校验完整 SHA-256 后返回实际路径与相对文件名。测试先在旧逻辑上确认失败，再验证修复。

已保存文件的核对分支原本在完成后保留“正在核对”状态，导致空队列仍看起来在处理。现在明确显示“已核对，复用已保存文件”，并在浏览器与 macOS 两条已有测试中断言完成提示；实际扩展重载后也确认提示正确。

## 合并前的实际环境检查

加载修复分支的 extension，并更新 macOS 助手（若使用系统集成）。确认“立即检查”仅更新索引；选择少量课件下载；暂停后重载扩展，再恢复；取消旧批次后重新下载同一文件；忽略再取消忽略；在专用测试目录验证迁移。测试时核对既有数据仍在，不对用户原课件做破坏性操作。

当前课件均已保存，小批次实际操作走的是核对复用分支，不能当作新增文件传输、传输中暂停/恢复/取消的证明。原生 Chrome 控制存在页面显示更新延迟，尚未可靠验收到传输中的停止操作。未移动或删除用户原课件来制造下载场景。

目前保留为草稿，尚不能宣称所有实际环境验证通过或保证不存在其他问题。提醒事项重新授权后的同步也需补验。

## 2026-10-19：系统集成权限恢复

真实 Chrome 中复现旧版 0.3.0 的 `chrome.runtime.sendNativeMessage is not a function`。扩展详情显示原生通信权限已获准，但加载目录仍是根目录旧构建。已更新该实际加载目录为修复版 0.4.0 并在 Chrome 重新加载。随后“启用 macOS 系统集成”和“检查助手”成功，显示原归档根目录。

修复保留可选权限：权限已获准但后台接口缺失时，仅在空闲状态下安排一次扩展重载；重载后验证助手，再启用系统集成并重新打开设置页。失败时保留原模式并显示错误，不循环重载。原生通信和文件夹选择共用接口缺失保护。

40 项测试及两个安装包构建通过。新增测试覆盖未授权不重载、接口缺失但已授权时的恢复请求、重载后助手校验、失败不误启用及不循环重载。真实 Chrome 验证了修复版加载与助手连接；自动重载恢复分支使用模拟 API 验证，未撤销用户已有权限来重建首次授权场景。本轮未测试学校登录、真实下载或提醒事项同步。

## 2026-10-19：凭据保存、连接检查与自动下载联调

现场错误为 `Frame with ID 0 is showing error page` 和 `No tab with id`，不能据此认定密码错误；同一浏览器直接进入 SSO 后能打开课程门户。首次检查未成功时尚无账户索引，定时检查不会自动启动；原“保存并启用自动登录”仅保存凭据，也没有开始首次扫描。现在保存成功后立即请求扫描。门户页面失败时经 SSO 恢复并重试一次，仍失败则显示网络或关闭页面的说明。

“检查连接”不再强制 CAS `renew=true`，优先复用有效会话；显式检查成功允许后续自动登录重试，仍保留每日密码提交限制。成功发现课程会更新认证状态并清除上一次扫描错误。“需要重新连接”改为准确的“密码自动重试已暂停”，避免把密码重试暂停等同于会话失效。

43 项 Node 测试通过，浏览器/macOS 构建与原生助手自检通过。新增覆盖保存后发起扫描、门户失败后的 SSO 恢复、有效会话不读取密码、显式检查恢复重试、错误页面和关闭标签页的提示。

真实 Chrome：完成 6 门课程检查、保留 98 个课件索引；单文件下载已归档，核实 PDF 文件头及非零大小。按用户选择开启编译原理、计算机网络、深度学习、计算机体系结构的自动下载，其余两门保持只扫描。扫描完成自动建立批次，下载至原有课程目录。传输中暂停时已有 34 份保存、55 份待继续；重新加载扩展后仍显示“恢复下载（55）”，索引保留；恢复后继续实际归档。显式检查连接后显示“自动登录已开启”和“统一认证连接正常”。

真实自动密码填表仍未验收：本次学校 SSO 会话有效，连接检查直接成功，不能据此证明保存的密码正确，也不能替代会话过期后的验收。验证码、真实取消批次、目录迁移、提醒事项与 Windows 实机限制仍适用。
